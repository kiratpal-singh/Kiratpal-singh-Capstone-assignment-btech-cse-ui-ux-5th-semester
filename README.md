Operating System Resource Management Simulator
An educational project developed using Python and Bash to simulate and understand major operating system resource-management concepts.

The application provides an interactive command-line interface to explore different algorithms, compare their performance, and understand how operating systems manage CPU processes, memory, resources, and disk operations.

Key Features
CPU Scheduling: FCFS, SJF, SRTF, Priority Scheduling, and Round Robin.
Memory Management: FIFO, LRU, Optimal Page Replacement, First Fit, Best Fit, and Worst Fit.
Deadlock Management: Banker's Algorithm, resource allocation safety checks, and cycle detection.
Disk Scheduling: FCFS, SSTF, SCAN, C-SCAN, and LOOK.
Data Visualization: Gantt charts, performance comparisons, and result graphs.
Bash Integration: System information, process collection, and log management.
Automated Testing: Unit tests for algorithm validation and input handling.
Technologies Used
Python
Bash Scripting
Matplotlib
CSV and JSON
Git and GitHub
Project Objective
To develop a practical learning tool that demonstrates how operating systems allocate resources, schedule processes, manage memory, prevent deadlocks, and optimise disk operations.
